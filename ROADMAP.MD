# WeStride - Platform Roadmap

## Demo Video

This is a very important task.  We need a 3 minute demo video of the platform.  Let's use things like "Playwright" to actually make the video from real browser use of the platform.

## Authentication - via Clerk

We'd like to add authentication for the platform via Clerk.  We want to support email login, Facebook login, Google login and Apple login.  Users should not have to register an account, but it would be helpful if the did, and would keep track of their progress, achievements, and unlock features like mentorship, and saving studio projects.

## Database

We need a database that our data can be stored in.  We would like to use a serverless Postgres database with Neon to keep costs down and scale as needed.

## Blob Storage - via Vercel

We need a place to store files for public and private use.  We would like to use Vercel's Blob Storage to keep costs down and scale as needed.

## Build Out AI Agent Coding Instructions/Markdown

We need to build out some files in this repo to help the AI agents write code for this project.

## Initial Features

This is our initial set of features/ideas that we want to complete in the hackathon.

### WeStride Academy

We would like to use Muse to generate an initial round of modules for the WeStride Academy.  These modules would be used to teach the basics of AI, prompting, agents, coding, entrepreneurship, and structured learning paths.

### Achievements

If a user is logged in, it would be cool to gamify the platform, allow users to earn achievements, badges, and XP for completing modules, projects, and challenges.

- "First 10 Users" on a project they built.
- "Completed AI Fundamentals" module.
- Mentored 1 Person.
- 100M Token Club

### Mentorship

We would like to allow users to request a mentor, and for users to offer themselves as mentors.  Users would complete a mentor profile including LinkedIn, Facebook, GitHub, and other relevant URL's.  Mentorship would be offered for free.

### Idea Studio

Users interact with Muse AI Assistant to generate ideas for businesses and nonprofits.

### Build Studio

Users interact with Muse AI coding tools to generate applications, websites, prototypes, and MVPs.

### Community

Users can share their progress, collaborate on ideas, form teams, and participate in challenges.

#### Events

Users can host local events or find events in their area.
