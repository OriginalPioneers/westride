# WeStride Academy - Track Database Seed Request

This describes the original prompt we sent to Muse to generate the initial 10 learning tracks for WeStride Academy.

## Model Used

muse-wonder-1.0

## Prompt Sent

Help me generate the initial 10 learning tracks for WeStride Academy, an AI education platform designed to help people learn about AI, develop practical skills, and eventually build their own ideas. The tracks should take users from beginner to advanced concepts, covering topics like AI fundamentals, AI models, generative AI, prompt engineering, AI agents, and real-world applications. We want to place a strong emphasis on Meta AI, Llama, and the broader Meta AI ecosystem while keeping the curriculum approachable, engaging, and useful for everyone.

Each track should have a compelling title, description, difficulty level, estimated duration, learning objectives, and a suggested number of lessons. Tracks will eventually contain video lessons, transcripts, and quizzes, with achievements awarded for completing lessons and tracks. For now, only generate the 10 high-level tracks, not the individual lessons. Structure the results so they can be seeded directly into our existing database and displayed in WeStride Academy, following our existing data models and conventions.
